# شجرة الشبكات — Computer Networks Exam Tree

موقع مذاكرة تفاعلي بشكل **شجرة** لمادة Computer Networks. ملف واحد مستقل (HTML + CSS + JavaScript) بلا مكتبات ولا اتصال بالإنترنت.

## التشغيل

افتح `network-tree.html` في أي متصفح (ويعمل بدون إنترنت). أو في VS Code: انقر بزر الفأرة اليمنى على الملف ثم Open with Live Server (إن كانت الإضافة مثبتة)، أو افتحه مباشرة من المتصفح.

## المحتوى (4 محاضرات)

| # | المحاضرة | عدد الأوراق |
|---|---|---|
| 1 | Introduction to Networking | 6 |
| 2 | Network Criteria, Protocols & Basic Concepts | 8 |
| 3 | Topology & Categories of Networks | 8 |
| 4 | Network Models | 9 |

كل ورقة فيها: Definition (اختياري)، Key points، Tip (اختياري)، Summary، وكل بند بالإنجليزية بجانب ترجمته العربية الأكاديمية.

## المزايا

- شجرة من 4 فروع: اضغط الفرع لتظهر أوراقه، واضغطه مرة ثانية لإغلاق الكل.
- علامات «تمت المراجعة» وعدّاد تقدم لكل محاضرة (محفوظة في المتصفح).
- بحث يدعم تطبيع الحروف العربية.
- وضع فاتح/داكن، وعرض: عربي + إنجليزي / إنجليزي / عربي.
- اختصارات: `/` للبحث، `Esc` للإغلاق، `←` `→` للتنقل بين الأوراق.

## هيكل الملف

- المحتوى كله داخل مصفوفة واحدة: `const D=[ ... ];` في وسم `<script>` الرئيسي.
- كل محاضرة: `{n, en, ar, T:[أوراق]}`.
- كل ورقة:

```js
{
  t:['English title','العنوان بالعربي'],        // مطلوب
  d:['Definition','التعريف'],                     // اختياري
  p:[['Point','نقطة'], ['Point 2','نقطة 2']],     // مطلوب
  x:['Tip','تلميح'],                              // اختياري
  s:['Summary','الخلاصة']                         // مطلوب
}
```

### قواعد كتابة النصوص داخل البيانات

1. كل نص مصفوفة من عنصرين بالضبط: `[English, Arabic]`.
2. استخدم علامات اقتباس مفردة للنصوص، ولا تضع `'` أو `"` أو `\` داخل النص. للفاصلة العليا استخدم `’` وللاقتباس العربي «…».
3. لا تكتب HTML مُهرَّبًا؛ الصفحة تهرّب النص تلقائيًا.
4. لا أسطر جديدة داخل النص، ولا تنسَ الفواصل.

## بيانات المتصفح (localStorage)

| المفتاح | الاستخدام |
|---|---|
| `netrev` | علامات المراجعة، بصيغة `{"<رقم المحاضرة>-<رقم الورقة>": true}` |
| `nettheme` | `dark` أو `light` |
| `netmode` | `both` أو `en` أو `ar` |

> لا تعِد ترتيب الأوراق داخل أي محاضرة، لأن علامات المراجعة محفوظة بحسب الموضع.

## التحقق بعد أي تعديل

1. فحص صياغة الـ JavaScript: انسخ محتوى وسم `<script>` الرئيسي إلى ملف مؤقت ثم نفّذ `node --check ملف.js`.
2. بصمة المحتوى العلمي: SHA-256 لكتلة `const D=[ ... }];` (من `const D=[` إلى أول `}];` يغلقها) في النسخة المعتمدة:

```
a28fa42269b3ca79270f49573def0857dc5023d6eb5537b334da1652710446e2
```

إن تغيّرت البصمة بعد تعديل واجهة فقط، فقد تغيّر المحتوى دون قصد.
